# eyemono VPM listing

VCC (VRChat Creator Companion) repository of eyemono's packages.

Add it to VCC: Settings → Packages → Add Repository → `https://eyemono-moe.github.io/vpm/vpm.json`
(or open <https://eyemono-moe.github.io/vpm/>).

| Package | |
|---|---|
| hitokoto (`moe.eyemono.hitokoto`) | VRChat avatar status bubble driven over OSC. The PC app is on the [Releases](https://github.com/eyemono-moe/vpm/releases) page. |

The listing and the releases are published by each package's release tooling; do not edit `vpm.json` by hand.
